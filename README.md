# 🤖 ComplaintIQ - AI-Based Customer Complaint Analyzer

ComplaintIQ is an AI-powered customer complaint management system built using
Streamlit and Ollama.

It allows customers to submit complaints and uses a local Llama 3.2 model
through Ollama to analyze the complaint automatically.

## 🚀 Features

- Customer complaint registration
- AI complaint classification
- Sentiment analysis
- Priority detection
- Complaint summary
- Key issue identification
- Root-cause analysis
- Company feedback
- Recommended action
- AI-generated customer response
- Complaint ID generation
- Complaint status management
- Complaint conversation threads
- Customer and support follow-up messages
- AI re-analysis of complaint threads
- Complaint search
- Department filtering
- Priority filtering
- Sentiment filtering
- Status filtering
- Complaint analytics
- Complaint trends
- Department-wise analysis
- AI business insights
- Attractive Streamlit dashboard

## 🛠️ Technologies Used

- Python
- Streamlit
- Ollama
- Llama 3.2
- Pandas
- JSON
